## 拟改接口

新任务以显式开关保存固定策略版本，只在 lazy 实验路径使用，默认关闭。复用 v4 图块和 v5 的前缀、修订机制，通过小型 `acceptance.json` 旁记录表达脚本与 Agent 各自的接受依据，不增加新决定版本。

旁记录绑定 task ID、观察包 hash/version、源 hash、精确决定文件 hash 和策略版本。逐项用现有 row、observation、transition 或 interval 路径定位，authority 仅为 script 或 agent。script 项记录同帧原生区域、实际 PTS/time_base、原帧 hash、有限规则结果和未决项；调用方写入 passed 不能代替计算。

存在未经 Agent 实际查看的项时，`visual_review` 保持 false，脚本读取不加入 `presented_images`。只有持久化开关、匹配旁记录以及重新计算的脚本依据共同满足时，混合决定才进入显式实验校验分支。agent 项仍需真实呈交和实际确认。导出来源分别记录脚本依据与视觉判断。

submit、export 和 replay 从当前原帧复验旁记录，复用已有几何、空间顺序、原生坐标、单帧裁剪、来源、DPI 和 PDF 检查，不构造伪称已看图的校验副本。接受历史保存旁记录与 hash；补采或修改来源、bbox、对应关系后重新绑定。旧任务与旧决定不自动迁移，没有开关的校验仍要求完整视觉审阅。

#50 保留每个 gap 和未决区间。普通 gap 可记录经重算的脚本依据，风险 gap 保留 Agent 前后原生证据；标题、速度、拍号、行外区域、首尾完整边缘仍由 Agent 核查。`hidden_content_proven_absent=false` 保持。

## 首版范围与验证

候选范围仅为固定比例、白底多行、单段、单向向上推进且有至少两条有序重叠的连续长谱。必须排除所有其他合理位移，包括较低重叠候选。内容只否决冲突，不能建立身份、合并重复音乐或排除几何候选。

普通行完整边界和细小行外符号的自动判据仍需建立真实正负例。当前 clean/complete 建议、无疑点或 `not_contradicted` 均不足以自动接受。缺判据、遮挡、partial、内容 uncertain、覆盖缺口、换页或布局变化进入审阅或 waiting。规则名称本身不构成证明。

离线验证覆盖上述负例、篡改绑定、关闭开关、历史修订和恢复，并在统一 CLI 核对原裁剪、灰度、DPI、整行分页和旧决定 replay。随后使用冻结三类真实样本，标准 URL 独立双跑，各自执行来源审计和保存决定重放。完整真实耗时与总 Token 均下降、质量无新增缺陷才可放行，未验证范围继续等待。
