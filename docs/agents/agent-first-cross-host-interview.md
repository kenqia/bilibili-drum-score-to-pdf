## 实施边界

默认 stage 使用 Agent 来源判断；显式 sparse 和 strict 保留原行为及不同的覆盖声明。同位置选源由 Agent 明确决定，程序不以清晰度分数代替音乐可读性判断。局部恢复复用已有任务和输入版本历史，只使直接依赖的材料及相关审阅失效。

本轮不包含远端写入、发布或更新共享安装副本的授权。历史交接中的发布授权不延用为本轮授权。
