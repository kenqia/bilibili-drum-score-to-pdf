# 实验任务的局部内容否决

显式 `--evidence-mode lazy` 的 v4 决定增加局部内容门禁，并须提供[标题、行外与整曲审计](coverage-audit.md)。v3 proposal 可由 builder 包装成单段 v4，直接提交旧版决定不能跳过实验门禁。它在现有五线几何、空间顺序、完整裁剪和原生证据验证之后执行，只检查决定已经提出的相邻匹配 pair。默认 full 和旧任务沿用原有决定验证与重放，不自动启用本门禁。

内容不建立身份。脚本不会寻找音乐相似行、按图像 hash 去重、合并后续重复段落或给没有几何重叠的窗口补身份。检测只读取原帧，不改裁剪、打印图或 PDF 像素，也不引入 OMR 或额外依赖。

## 检查什么

每个已提出的 pair 从真实原帧读取五线锚点附近的局部窗口，顶部保留四个间距、底部保留八个间距。五条长线的共同支撑仍须覆盖原帧宽度的 45%，分析横向范围则取这五条长线 band 的并集。一条线被截短时，其他长线旁的记谱仍参与分析，不能随共同支撑截掉。窗口不随调用方把 crop 缩小而隐藏内部记谱；crop 排除原生五线、缺少上下完整边界或 partial 观察均等待复查。原有遮挡检查继续执行。

分析使用灰度 ink，滤出五条长线对比较的影响。保留非五线记谱支撑，并为原生编码噪声允许一个像素邻域。完成既有原生窗口、五线、遮挡和信息量检查后，把局部 ink 放回同原帧绝对 x 坐标的全宽分析 mask，外围仅补零。原局部 ink 的全部像素与位置保持，不裁交集、不移动或缩放记谱，不改原裁剪及打印像素。这样共同五线支撑左缘的一列波动不再造成窗口宽度不同而无法比较。原窗口之外的记谱仍由完整原生审阅与行外审计负责，补零不能证明那里没有内容。

窗口高度、原帧宽度不同或 spacing 差超过 .1 时仍保持 uncertain，不缩放对齐。不可靠五线、低信息、明显光标、密集遮挡或背景不足同样保持 uncertain。相同遮挡图像不能因为像素相同就通过。3×3 像素邻域、.08 非矛盾界限与 .45 冲突界限保持；新增可比较的原生内容仍可能有歧义或 conflict，不能以窗口修复覆盖这些理由。

输出有三种状态。

| 状态 | 含义 | 行为 |
| --- | --- | --- |
| `not_contradicted` | 本次有限局部检查没有发现明显矛盾 | 继续已有提交检查，不能据此证明身份、全谱覆盖或没有任意遮挡 |
| `conflict` | 局部非五线记谱存在明显矛盾 | waiting，不接受决定、不生成成功 PDF |
| `uncertain` | 原图、完整边界、支撑或对齐不可靠，或差异处于不确定范围 | waiting，保留实际 pair、来源与处理入口 |

灰度阈值、ink 支撑及差异界限是当前合成验证中的保守参数，尚未形成真实视频的放行范围。任意复杂遮挡和细小符号仍依赖 Agent 原生审阅；检测器未发现遮挡不证明候选绝对干净。`visual_review=true`、说明文字和较高置信度都不能覆盖已经检测到的 conflict 或 uncertain。

## 从等待恢复

沿用 `build-decision` 的结构修正与实际审阅确认。纠正对应或恢复实际完整 crop 后，再绑定当前观察包构建。`supplement` 仍用于取得局部原生证据，但只有修正后的所有必需对应都有可靠局部内容时才能解除门禁。缩去矛盾音符、改确认标志或绕过构建直接提交不会解除门禁。不能取得可靠证据时继续 waiting，预算不放宽。

未启用最小证据链的任务保留全部观察与共同实例对应，没有间接 clean-witness 协议。光标或遮挡污染某个必需对应原帧时，补一张 clean 帧或改选打印来源仍不能删除旧对应中的 uncertain，该任务继续 waiting。不能宣称任意遮挡都可用补采恢复。当前可到达的 uncertain 恢复正例是修正实际完整原生 bbox，恢复被错误排除的五线范围；它不改原帧或缩小观察范围。

`build-decision` 的 `sources.content_checks` 保存检查结果。`submit` 重新检查并将成功依据写入任务的 `content_checks`；`export` 和 `replay` 再次检查，并在 manifest 保存同名结果。冲突与不确定项通过公开 `issues` 或草稿未决项返回。审计包含源 hash、帧 hash、实际 PTS/time_base、pair、staff_y、提出的 bbox、局部窗口、差异与有限分析像素，明确标记内容没有建立身份。

`content_validation` 阶段记录耗时。统一 `report.content_validation` 按实际发生的检查累加 pair、分析像素、conflict 和 uncertain 次数，包括失败或等待成本。builder 为严格字段校验和实际确认分别验证草稿，重复执行的检查分别计数；重建 report 不增加检查。分析像素不是模型图像输入或 Token。宿主计量缺失仍保留 null。

## 显式最小充分证据链

新 lazy 任务可指定 `--minimum-evidence-chain`，固定 `ordered_anchors_v1`。旧任务不能迁移，默认 full 和未指定开关的 lazy 保留原内容门禁。这个实验区分承担接续证明的内容证据与冗余诊断，仍检查所有提出的共同实例对应，任何明确 conflict 都否决。

每个相邻区间需要两个独立、有序的空间实例内容证据。优先使用当前对应，也可检查现有原帧之间的几何桥。桥的所有共同实例均检查后才选择锚点；空间实例必须在桥覆盖的每帧完整出现，global_y、尺度、横向布局和原有共同位移保持一致。不跨谱面段，不跳过中间帧的审计，不利用内容创建身份。每次完整决定重算共享最多 256 条桥对应，所有谱面段合计，额度用尽而关键证据仍缺失时保持 waiting。所有实际比较读像素与失败检查计入原 content_validation。

桥比较先筛选至少两个不同实例在全中间帧完整、几何合格且两端已有实际原生 clear 核查的端点边，再按距离及时间顺序检查。明知不足两个锚点的额外桥不消耗比较预算，原必需相邻对应仍全部检查。clear 声明只决定比较顺序，不证明内容一致。每条被检查的桥仍比较全部共同实例，包括不能作为锚点的第三实例；发现明确 conflict 就等待。

`review.native_clean_regions` 复用既有原生核查字段，绑定真实 PTS、原帧 hash、同帧原生细节和实际呈交清单。内容锚点需要 clear cursor 与 clear occlusion，范围完整覆盖分析窗口和观察框。冗余光标对应只在充分链已成立、Agent 已实际确认该窗口 cursor present、occlusion clear 时才不阻塞；未知遮挡、缺记录、低信息、partial、丢失边界或内容差异不降级。每端的检测理由分别保存在 endpoint_reasons，任意一端有不可替代的硬理由都继续阻塞，另一端的光标不能掩盖它。检测到光标的端点必须有 actual present 声明；all-clear 声明不能覆盖已检测光标。尺寸舍入导致的 unreliable_alignment 还要求两端真实 clear 原生核查。标题、首尾、行外内容、每帧每区间覆盖与所选打印来源都继续执行原审计。

原生声明按与当前分析窗口或观察框有面积交集的范围匹配。任一相关声明有 cursor uncertain 或 occlusion present/uncertain，必需对应和已检查桥都保持 blocking，即使像素结果为 not_contradicted、另两个锚点已有充分证据，也不能解除。宽范围 clear 声明不能覆盖局部未知或遮挡声明；其他位置的无关声明不污染该对应。像素 status/reason 保留原值，native_blockers 另列实例、端点帧、原生范围和声明理由。

可靠的冗余非锚点没有相关未知或遮挡声明时，不强迫追加 native 记录；缺记录的实例不能成为 clean 锚点。不可靠或需替代的对应仍要求完整原生 authority。实际 cursor present 即使未被有限检测器发现，也只能在充分替代链和完整 present/clear 原生核查同时成立时不阻塞。

构建保存小型 `continuity.json`，绑定 task、观察版本/hash、源 hash、精确决定文件 hash、固定策略和原生核查记录。submit、export、replay 从原帧重新比较；接受历史保存旁记录及 hash。改变观察、补采、改来源或改决定后须重绑。没有旁记录或绑定不符时不能导出。未采样隐藏内容仍未知，脚本读像素不作为实际图像呈交或 Token。
