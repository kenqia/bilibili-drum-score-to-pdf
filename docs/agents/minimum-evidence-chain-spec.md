## 02 充分链与定向补采，P0

区分完整几何对应和承担接续证明的可信内容证据。全部空间观察、共同位移、帧内顺序、全局位置、空间实例、首尾、行外区域和逐个时间区间的覆盖要求均保留。内容只能检查已通过几何的对应，不能创建身份、删除其他合理位移或合并重复音乐。
