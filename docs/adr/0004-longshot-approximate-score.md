# 以长截图和局部推测简化鼓谱 PDF 主线

当前产品入口与生命周期由 [ADR 0006](0006-script-product-lifecycle.md) 替代。以下保留历史决定。

2026-10-20，用户接受 Q1–Q3 全部推荐，确认将主线收敛为下载视频、自动长截图、生图优先或矢量兜底、A4 排版。新目标允许局部符号推测，优先完成可打印鼓谱，减少 Agent 逐行选框、修边、补采和来源审阅填报。

固定比例的纵向滚谱是首版范围。蓝标、水印和轻微接缝不阻止处理；长图过长时沿完整谱行分块送生图，最终打印分页独立处理。

允许模型推测模糊或遮挡的局部符号，交付时统一说明可能存在推测。整小节、整行缺失优先修复拼接，不凭空续写整段音乐。整体查看长图、生成结果和全部最终页面，检查明显漏行、重复、裁断及排版；不逐符号校对，小疑点不阻止交付。每块最多一次定向修正，之后采用已有较好结果或矢量。轮廓转描不具备推测隐藏符号的能力。

这项决定调整旧 PDF 流程不得猜音符的约定，并替换新主线的逐行来源门槛。匿名获取、资源保护、原始来源保留和输出不覆盖继续保留。旧实现及历史验收仍按其当时要求解释，不追溯更改结果。

程序已在独立分支实施，安装 Skill 尚未更新。用户工具仅作为算法参考，新实现没有固定擦边和抹角。真实《山海》已完成长图及四页矢量 PDF 的整体查看，《空空》及真实宿主生图仍未验证。访谈及后续验证范围见[设计记录](../research/2026-10-20-longshot-design-interview.md)。
