# PDF Skill 只保留 Agent 取谱路线

2026-10-20，用户确认删除 sparse/strict、将 MIDI 移出 PDF 包、保留生图优先及失败转矢量，并精简来源审阅。暂不另建 MIDI Skill。

旧包虽然默认不扫描，但仍暴露扫描入口及大量可选协议。Agent 主动切换后，自动疑点会成为逐项销账要求；人工流程本身也需要每对相邻谱行的重复字段。这增加了采样和说明工作，不能代替实际看图。

本次同时删除专属代码、命令、OCR 依赖与运行协议。共享冻结及裁剪校验保留在任务层。来源审阅只保留一份说明覆盖谱名、首尾与接续，所选原生截图仍需 present，真实未决项继续阻断。默认阶段入口不再接受模式和扫描预算。

取舍是放弃程序扫描及 MIDI 的当前可调用能力，换取单一路线和更少误入分支。旧实现由 Git 历史及安装备份保留；旧扫描任务使用旧版或另建任务重新审阅。没有移除匿名网络、资源、引用和裁剪保护，也没有将程序检查视作音乐校对。

回滚使用更新前的完整安装备份或独立旧提交工作区。验证使用公共入口、恢复预算、裁剪拒绝、全部预览版本和仓库外运行测试；真实视频与宿主生图仍需单独实际验收。
