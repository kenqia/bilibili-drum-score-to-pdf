# 正常 PDF 来源判断由 Agent 负责

2026-10-19，用户确认正常 PDF 任务由 Agent 负责来源判断，自动稀疏导航与严格扫描作为显式可选辅助。跨宿主执行已暴露自动导航阻碍人工来源审阅的问题，因此默认阶段入口返回可操作的来源任务，不主动启动扫描。显式扫描保留自身 provenance 和实际覆盖范围。

Agent 审阅以标题、音乐起点、末行和相邻来源接续的结构化证据为依据，并分别记录相关自动疑点的处理结果。自动检查原记录保留，来源损坏、非法裁剪及未解决的音乐完整性问题继续阻止后续操作。程序验证引用和状态，不能把程序回执记作实际看图。

这一决定取代正常流程必须通过自动导航的假设。已有合法人工冻结且来源未变的任务继续恢复；新任务及修改来源后的人工审阅采用新契约，并要求所选原生图的 present 记录。本记录不代表实测已经通过。
