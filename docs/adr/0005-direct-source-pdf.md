# 默认直接排版长截图中的谱面

当前 Skill 与程序/网站的产品边界见 [ADR 0007](0007-independent-skill-and-website.md)。本文保留历史决定；Skill 的当前执行规则以分发包协议为准。

2026-10-20，用户分两轮确认五项推荐，将新任务默认路线改为长截图、可安全执行的局部去水印、完整谱行等比 A4 排版和全部页面实际查看。清晰谱面不再必须经过重绘或轮廓转描，以保留已有记谱外观，避免新增生成变形和调用修正。

局部去水印仅处理确认没有音符、五线、标题和署名的区域；重叠水印先保留。轻微模糊、底色及残留水印不阻止交付；明显缺行或重复先修复拼接，严重遮挡优先查找原视频清楚画面，仍无法恢复时说明限制，不自动猜符号，也不把已知缺段称为完整谱。

重绘和矢量保留为用户明确要求才启用的可选路线，已有任务继续恢复。此决定替代 [ADR 0004](0004-longshot-approximate-score.md) 中新任务生图优先、矢量兜底的默认路线；原有来源、网络、资源、版本和终稿审阅保护保留。原图直排不代表音乐零风险或已逐符号校对。

设计已确认并完成首轮实施，首轮验证使用合成视频、受控审阅与确定性检查，不作为真实视频或页面视觉验收。初始决策和边界见[设计访谈](../research/2026-10-20-direct-source-pdf-interview.md)，后续试用修正及保存材料的实际页面审阅见下方记录。

2026-10-21用户接受紧凑分页：自动试算最多缩小10%，仅在能减少页数且最小五线间距至少4个PDF点时采用，页内继续保持连续空间关系。显式切口保留原满宽比例，最终仍检查全部页面的字号和记号归属。原始像素保留不等于印刷尺寸不变。

2026-10-20试用修正：原图打印按每页连续条带保留原行距，避免逐行重新插入空白改变关联记号的位置关系。分页切口需实际查看，歧义处整组保留，详见[设计记录](../research/2026-10-20-continuous-page-boundaries.md)。
