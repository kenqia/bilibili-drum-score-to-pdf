# 首发面向已有视觉 Agent 的 Skill 用户

当前产品入口与生命周期由 [ADR 0006](0006-script-product-lifecycle.md) 替代。以下保留历史决定。

2026-10-12，用户确认首发面向已经使用 Codex 等视觉 Agent、愿意安装 Skill 的人，沿用 Agent 审阅与脚本执行的交付形态。首发输入限定为视频中已有的固定比例、白底多行鼓谱，向上滚动时有可靠重叠，或有序翻页时可以确认接续；横向滚动和没有谱面的演奏视频不在范围内。这个决定让安装、使用说明和真实样本验证围绕现有 Skill 展开，暂不建设普通鼓手粘贴链接即取 PDF 的独立服务。

用户希望跨主流 Agent 使用，采用自然语言安装入口，不把产品定位限定在一个宿主。兼容性是待验证的目标，不等于已通过全部宿主测试。质量门槛和首发验收仍未确定，本决定不代表已满足发布条件。
