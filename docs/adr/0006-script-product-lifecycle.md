# 纯程序与匿名网站生命周期

2026-10-22，[ADR 0007](0007-independent-skill-and-website.md) 替代本文删除 Skill 分发与测试的产品范围决定。以下保留当时的实施记录；程序与网站的生命周期、安全和存储契约继续有效。

2026-10-21，依据 #69 及 #70–#73 的明确实施授权，将仓库产品收口为共享 Python/CLI 与独立 worker 的匿名网站。此决定替代 ADR 0001–0005 的产品入口、模型编排、人工批准和旧任务恢复规则。历史实验与素材继续保留。

单机串行工作负载复用 SQLite 和 OS 文件锁，不新增生产依赖。转换保留已有谱面图像、统一比例和完整连续条带，不调用模型、识别音符语义或生成 MIDI。已知来源歧义明确失败，自动完成保持 reliable=false。

下载/解码的四个复用模块迁入 drum_score 包，所有安全测试按语义迁移。删除旧 Skill 分发、专属入口与专属测试，迁移对应见 docs/test-migration.md。已安装 Skill 和旧任务不自动变更；历史版本用独立 checkout 查看，不将其协议作为新任务入口。

网站完成决定持久化后，保留 PDF、全部预览与诚实来源清单 24 小时。原生帧、长图及获取视频在结束后清理；失败仅保留限时限额脱敏诊断。清理按登记身份进行，未知文件和替换物不接管。已合法打开的 Linux FD 可在 unlink 后继续读取。

服务 schema 显式版本化，未知或旧未版本化库拒绝启动。恢复到新目录需重新核验并登记受管文件的实际 inode/ctime，保持原期限。入队、重试、恢复后的领取和运行都检查同一容量规则，不删有效结果来兑现新任务。

回滚使用匹配的程序和完整数据备份；不自动迁移旧任务。公开部署、目标主机硬资源验证及正式备份恢复工具另按 #74 交付与授权。
