## What to build

用户能够组合使用手动区间、手动或自动谱区、覆盖物开关、按需补帧和来源缓存，获得可亲自检查的PDF及全部页面预览。维护者取得成功来源回归、独立保留来源和资源验证证据，明确改进与尚未解决的限制。本票承接原T9，不重新建立独立的前置复现任务。

## Acceptance criteria

- [ ] 组合验证默认提交、时间选择、谱区、覆盖物开关、缓存命中、排队和重试的参数与实际产物一致，无本站来源视频预览，超过600秒原来源始终拒绝。
- [ ] 汇总每类修复的真实案例TDD证据，包含修改前复现、失败验证、修改后改善和来源身份；尚未改善的案例明确列出，不将未复现问题写成已修复。
- [ ] 对已有成功来源验证原谱位置、首尾、后续重复音乐、关键记号、完整谱行、原行距和统一比例；无需要求不同算法生成的文件hash完全相同。
- [ ] 使用未参与调参的实际来源验证泛化，开发集与保留集分别记录，不以已知案例全部通过声称所有未知视频都支持。
- [ ] 自动测试、合成重放、实际来源重放和实际看图分别记录；complete仍只表示完整产物发布且reliable=false，用户亲测负责最终谱面体验，工程验证不得省略。
- [ ] 完成程序针对性与全量回归、离线重放及独立安装验证；保留独立Skill边界和并行打印版式改动，验证取消、期限、受管清理、来源保护和输出不覆盖。
- [ ] 在隔离环境验证八路配置中补帧与缓存协调的时间、内存、磁盘、取消和故障隔离，记录实际预算及未验证项。本票不自动授权生产压测或服务器配置修改。
- [ ] 提供来源标识、实际区间、前后PDF、全部页面预览及资源摘要供用户亲测，未知成本为null，不附认证或敏感日志。
- [ ] 更新最终支持范围、已知失败、显式升级和回滚步骤。推送、PR、生产部署及正式数据迁移另行授权，不自动关闭父工单。
