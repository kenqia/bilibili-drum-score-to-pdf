## What to build

用户直接获得更可靠的自动谱区检测和配准：多时间点画面预检、固定覆盖物 Mask、问题区间按需补帧，以及通过实际多帧内容确定候选拼接路径。普通来源默认0.5秒采样，PDF忠实保留来源画面和署名。该能力直接进入自动转换流程，不限定为旧流程失败后的单独恢复路线。

本票合并原 T5、T6、T7。取消独立的复现准备票，把真实案例复现和 TDD 作为每类修复自身的验收条件。可独立于手动选项和缓存开发，在公开转换入口验证，并将自动忽略固定覆盖物开关贯通网站提交、队列、重试和结果记录。

## Acceptance criteria

- [ ] 每类拟修问题至少使用一个核验过的实际来源复现；先建立失败验证，再修改并确认同一来源的改善，保留来源 hash、实际 PTS/time_base、失败区间及前后产物。先核验现有媒体，身份不足或缺失才按授权匿名获取，不自动接管或清理实验文件。
- [ ] 画面预检位于下载后、完整采样前，检查多个分散时间点。单点黑屏、片头或未检测到五线不构成充分拒绝证据；不确定时继续，明确不适用时才提前停止。记录取样及拒绝依据。
- [ ] 自动谱区依据五线结构、连续有效区域和时序证据选择，交付保留关键记号、完整谱行和相关边缘内容，匹配区域与交付区域分别核验。
- [ ] 固定覆盖物 Mask 需要跨多段真实滚动确认；暂停音符不误判，粗对齐不足时不凭静止生成遮罩。大面积覆盖须检查剩余有效信息量。
- [ ] profile 和独立像素重叠核验一致使用无效区域，在候选位移对齐后排除任一帧的无效像素。信息不足时补证或明确失败，不只修改 profile。
- [ ] 网页提供自动忽略固定覆盖物开关，默认开启，参数与重试、结果记录一致；未与高级选项票合并前仍可独立通过网站提交及转换验证。
- [ ] Mask只影响位置计算，不擦除原始 RGB、署名或水印，不推断被遮挡符号。
- [ ] 默认0.5秒采样，无法匹配、歧义或快滚区间按需细化至0.25秒、0.1秒；补帧受明确区间、次数、总时限、内存和临时空间预算约束，并可取消。
- [ ] 保留多个匹配候选，使用多帧实际重叠、局部细节、方向和位移一致性确认路径；不靠扩大搜索范围、调松阈值或单凭运动平滑选中重复乐段。证据不足继续失败。
- [ ] TDD回归覆盖快滚、重复系统、暂停、固定 Logo、动态背景、大面积遮罩及真正缺段。验证后续重复音乐、首尾和实际嵌入像素；翻页不得只发布第一页并声称完整。
- [ ] 根据实际案例决定新增布局支持，未验证前不承诺翻页、横滚或变焦通用支持；保持完整谱行分页、原行距、统一比例与 reliable=false。
- [ ] 新增诊断仅含安全的阶段、区间、候选和资源证据，不保留认证、签名地址或原始网络日志；更新支持范围和验证文档，不修改独立 Skill 或执行部署。
