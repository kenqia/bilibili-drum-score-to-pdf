## What to build

网站对同一来源的重复及并发转换复用已验证视频，减少重复下载，同时保证来源准确、空间有界和取消隔离。缓存保留24小时，总额1GiB，与PDF结果分别管理，不能绕过原来源600秒限制。

## Acceptance criteria

- [ ] 缓存身份区分BV、分P、CID与已验证媒体版本，记录hash、完整时长及尺寸；身份不足、来源变化、损坏或过期不直接命中。缓存命中不绕过前置来源时长和完整性限制。
- [ ] 同来源并发获取合并，未完整验证和发布的媒体不能命中。取消一个等待者不破坏其他任务需要的获取或持有中的来源；等待、获取与转换均受取消和总时限保护。
- [ ] 缓存发布后24小时到期，访问不续期；已发布和写入中的缓存合计不超过1GiB，缓存与任务临时空间均纳入实际磁盘及空闲水位规划。
- [ ] 清理只作用于身份登记匹配且未占用的缓存，优先过期项，空间不足可回收未占用旧项；持有中的来源、有效PDF、未知文件、身份替换物和历史实验均保留。
- [ ] 无法释放容量时跳过本次缓存写入，按已有任务临时预算转换，不突破缓存上限，不提前删除有效结果。
- [ ] 不自动将现有实验文件登记为可清理缓存；仅在来源和hash核验后进行显式复用，不读取真实认证，不存签名媒体地址或原始响应。
- [ ] 真实临时文件、传输边界与任务进程测试覆盖命中、实际下载次数、分P/CID隔离、损坏、期限不刷新、并发合并、取消隔离、进程崩溃、半份发布、空间回收和symlink/inode替换。
- [ ] 如修复实际缺陷，每类至少有一个真实案例先复现并建立失败验证，再修改并确认改善，按TDD记录前后证据；不把新功能测试冒称历史缺陷复现。
- [ ] 提供所需的显式schema升级、受管身份登记、备份恢复和回滚验证，恢复不刷新期限，未知schema仍拒绝；不执行正式服务器迁移。
- [ ] 网页重复提交能完成实际缓存命中转换，结果保留来源与资源证据，交付权限不因共享来源缓存而改变；更新运维和网站文档。
