# 鼓谱 PDF 架构

视觉 Agent 负责判断原谱位置、接续、完整谱行、真实生图结果和最终页面。本地程序负责有界匿名获取、实际 PTS 解码、引用校验、裁剪拼接、轮廓转描和 A4 排版。脚本不内嵌模型调用。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| convert.py | CLI 操作及 JSON 请求适配；稳定错误码和完整回执摘要 |
| score_workflow.py | 准备、人工取帧、呈交、局部修改及阶段推进 |
| agent_source_review.py | 一份来源审阅及原生图呈交引用校验 |
| score_task.py | 来源冻结、引用完整性、裁剪检查、原子发布、生图历史与预算、终稿版本 |
| reconstruction.py | 本地取帧、整数裁剪、粗拼、轮廓转描与五线修复、完整行排版 |
| native_cache.py | 有界原生候选缓存、晋升及实际解码统计 |
| video_seek.py | ffprobe、有限时解码、实际 PTS/time_base 和临时资源清理 |
| public_video.py、anonymous_backend.py、anonymous_network.py | 匿名公开视频获取、网络校验及脱敏诊断 |
| delivery_layout.py | 跨 Windows/WSL 的 PDF 文件名清洗 |

## 来源与排版

Agent 查看原生首尾图，根据实际重叠、小节编号或有序翻页补采中段。选区包含原生截图引用、整数 bbox 和明确原谱 position。一个位置选择一个完整来源；不同位置相同音乐分别保留。没有印编号时不推断隐藏编号。

`source_review` 保存 viewed_captures、complete、unresolved、notes、continuity 和 first_last。当前工作流以 agent-source-review/2 校验完整审阅的所选截图都已通过 present 登记。登记只保存 Agent 的声明，不证明模型实际看图。

`score_task` 校验源文件和产物 hash、路径、完整裁剪及冻结身份。选行变更先构建版本化材料，再与失效决定一起原子发布。无效参数和发布中断保留原有效记录。真实未决音乐或接续仍阻止生图和导出。

标题和完整谱行或连续行组等比重排，短行保留自然宽度。分页发生在完整单元之间。layout 只改变打印版本，不重新生成谱面。每次导出保留独立 output_revision、全部有序预览及 hash；最终审阅必须覆盖当前版本全部页码。

## 生图与矢量兜底

生图组独立于打印分页，按连续完整选区组织，限制行数、总像素和有效五线分辨率。Agent 先查看粗拼，再批量预留请求。prepared 请求通过 dispatch-redraw 进入 calling；重复读取返回原 ID，不能重复发送未知调用。

真实结果以同一 request 回填。Agent 对照原谱查看结果，提供完整行边界。每组每个输入版本最多一次定向修正；失败、工具不可用、修正仍拒绝或确认无法恢复的未知结果转矢量。矢量只转描可见几何，不做音乐识别或隐藏符号恢复。

输入身份绑定有序来源 hash、实际 PTS、原谱位置、裁剪及五线几何，不包含任务路径与打印布局。恢复相同输入沿用接受材料、调用身份和修正额度，未变组继续复用。历史版本保留在 generation_history 与 output_history。

## 输入和资源保护

公开来源只接受规范 HTTPS B站 BV URL 及合法分 P。匿名后端不加载用户配置、Cookie、netrc、插件或模型认证。公共 DNS 地址、TLS 主机名、协议、媒体域名和重定向逐项校验，拒绝私有地址和带凭证 URL。签名媒体 URL 和原始异常不写入公开日志，代理不转发凭证。

默认沿用环境代理。仅代理 CONNECT 403 或视频网页 HTTP 412 触发一次公开 API 直连恢复，共享原期限，不持久修改代理。BV、分 P、试看、API 时长及实测时长核对后才接受来源。代理 407、普通来源 403 和其他网络错误不触发此恢复。

下载、重试和探测默认共享 1800 秒总期限。原生解码累计 600 秒、单次 60 秒；取消和失败清理临时资源。原视频与派生产物分开保留，完整文件独占发布，已有产物不覆盖。来源或产物损坏、路径逃逸和越界裁剪停止任务。

## 兼容与支持范围

保留原手动任务的有效来源和生成材料恢复。已有程序扫描任务不自动升级为 Agent 批准，需要继续使用旧版备份或在新目录重新审阅。旧实现和旧 MIDI 能力保留于 Git 历史，本 PDF 包不加载它们。

支持已有白底多行、固定比例、向上推进或可确认有序翻页鼓谱。没有谱面的演奏视频、横向滚动、比例变化或无法确认接续的布局不强行交付。历史 Codex 样本验收不代表本版新宿主或真实整曲验收通过。
