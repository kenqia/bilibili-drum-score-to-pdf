# 截图与重绘架构

新版默认流程从用户提供的公开 URL 或本地视频准备任务。视觉 Agent 判断导航、整曲接续、谱行边界、真实生图结果和每页 PDF；本地程序负责有界获取、实际 PTS 解码、hash 校验、裁剪拼接与确定性排版。程序没有内嵌模型 API。

## 模块边界

`convert.py` 是命令适配层，将操作与 JSON 参数交给 `score_workflow.py`。工作流记录低清导航、原生截图、实际呈交、空间位置去重、粗拼、宿主调用与修正状态。`reconstruction.py` 提供本地媒体、来源校验、选行、轮廓转描与补五线、完整行 A4 分页。`delivery_layout.pdf_name` 清洗跨 Windows/WSL 的谱名。

`public_video.py`、`anonymous_backend.py` 和 `anonymous_network.py` 保留匿名获取与网络保护。`video_seek.py` 保留 ffprobe、实际 PTS/time_base 解码与临时资源清理。`midi_workflow.py` 与 `midi_export.py` 独立实现明确请求后的完整音乐转写、用户授权近似播放、GM 鼓轨导出与实际事件回读；Mido 可选，普通 PDF 无需加载。

旧 agent_* 编排、viewport 身份跟踪、干净候选门禁、旧决定兼容与性能协议已移除。旧任务不迁移，历史实现通过 Git history 查看。

## 来源与重绘

原截图允许水印、播放矩形和高亮。Agent 对无法确认的音乐内容局部补采；轮廓转描不能恢复完全隐藏的记号。相同空间位置只保留一次，后续同内容重复音乐使用新位置。标题、速度、拍号、署名、首尾和行外符号保留。

粗拼分块按完整谱行形成真实宿主生图输入，每页最多一次定向修正，预算在调用之前写入。失败、无工具和修正拒绝转矢量。已接受结果后发现错误可撤回；旧结果和拒绝依据保留，当前 PDF 审核失效。新导出按来源宽度统一比例，保留短行，只在完整行之间分页，不预先重采样生图。

`record.json` 保存轻量来源与派生引用，恢复验证所有引用 hash。变更选行与重绘失效原子发布，验证失败保留上个有效状态。导出使用版本目录，避免重名覆盖；最终 review_pdf 验证整个任务后登记实际每页审核。保存文件不能证明 Agent 看过。

## 输入和资源保护

公开链接只接受规范 HTTPS B站 BV URL 及合法分 P。匿名后端不加载用户配置、Cookie、netrc 或插件，媒体使用公共 DNS 地址与 TLS 主机名校验，拒绝私有地址、不安全协议、带凭证 URL 和不安全重定向。签名媒体 URL 和后端原始异常不写入公开日志。代理不转发凭证。

下载默认总期限1800秒，下载、重试、probe与发布共享期限；保留下载大小限制、实测媒体尺寸校验、完整文件独占发布和中断清理。CLI 获取失败只写已脱敏 acquisition-only 诊断，目录没有其他用户内容时允许重试。原视频在相邻独立来源目录保留。获取过程中 SIGTERM 停止实际工作进程，输出不出现半成品视频。

原生解码累计600秒、单次最多60秒。导航另有低清解码边界，实际数量单独记录。取消旧固定补采轮数不解除资源保护。任务拒绝损坏来源、越界裁剪、未决完整性和路径逃逸；MIDI 输出限制在任务目录内。模型或完整宿主成本不可取得时为 null。

## 回滚和支持

切换前基线见[验收调整](agents/reconstruction-acceptance-amendment.md)。回滚在独立 checkout 恢复旧源码，使用新任务和结果目录，保留所有现有证据；不让旧代码续跑新版任务。修改仓库 Skill 不等于已经更新宿主安装、认证或配置。

支持已有白底多行、固定比例、向上推进或可确认有序翻页鼓谱。其他布局明确报告限制。实际三曲 PDF 和近似整曲 MIDI 已在 Codex 验收，其他宿主没有整曲验证，不推广为普遍准确率或成本收益。
