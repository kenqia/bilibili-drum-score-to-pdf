# 鼓谱 PDF 架构

主线为匿名下载或读取本地视频、自动长截图、宿主生图优先或轮廓矢量兜底、A4 排版。视觉 Agent 整体查看长图、生成结果和最终全部页面。允许推测模糊或遮挡的局部符号，小疑点不阻止交付；整小节或整行缺失修复拼接，不凭空续写整段音乐。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| convert.py | CLI 和 JSON 适配、稳定错误码及完整回执摘要 |
| score_workflow.py | 来源准备、阶段推进、宿主生成与 PDF 渲染 |
| longshot.py | 行投影相关估计位移、停驻帧中值、长图合成、整行切分和整体审阅 |

| delivery_layout.py | 跨 Windows/WSL 的 PDF 文件名清洗 |

## 长图与生成

prepare 记录原视频，新任务标记 workflow=longshot/1。stage 顺序解码采样，返回 longshot_review；review-longshot 保存一次实际整体查看及谱名。实际原帧、派生长图和视觉审阅分别记录，不将拼接长图标为原生截图。

位移相关按实际重叠范围归一化，避免相似五线谱因未移动时重叠面积较大而被误判。对相近相关峰比较二维墨迹重叠，减少相似谱行间的错位。空白片尾和非谱面黑场保留在采样与首尾记录中，不混入谱面中值。相同位移的帧取有界中值，按累计位移叠加；保留短时停驻和最终真实帧，不要求每组至少三帧。默认不裁左右、不擦右上角、不删除浅色区域。低置信度记录为提示，交给整体目检，不逐像素拒绝。

完整谱行之间选择可见空隙切分，上下记号交错且无空隙时保留连续行组。首块保留谱名与标题。生图分组独立于打印分页，保留符号分辨率；整体审阅通过后自动预留全部请求。宿主实际执行生图，脚本不读取模型认证或内嵌 API。

prepared 经 dispatch-redraw 进入 calling，重复读取沿用原 ID；结果未知先恢复。生成图整体查看后自动取得行边界；去除标记使连续行组自然分开时，按组内五线数量合并回原组。明显增删行时定向修正一次或转矢量。轮廓路线仅描出可见外形，不恢复隐藏音乐。输出统一附近似说明及 reliable=false，不声称音乐等价。

## 状态与排版

任务继续使用 score-reconstruction/1，新增 longshot 材料记录；已有手动任务不自动重拼。原视频、原生首尾、实际采样时间、位移和长图 hash 分别保留。重拼使用新版本目录，撤回当前生成选择和 PDF 批准，历史文件与调用额度保留。

长图不经过旧的逐行来源表或墨迹触边门禁，程序只验证切分连续覆盖长图及文件引用。旧手动任务仍使用其明确来源契约。两种材料复用同一生图恢复、矢量渲染和终稿检查。

所有谱行统一比例，分页只发生在完整单元之间。layout 只改变打印版本，复用生成结果。导出保存独立 output_revision、材料清单和全部有序预览；review-pdf 必须覆盖当前版本全部页面。检查顺序、首尾、明显缺行、裁断与打印观感，不逐符号校对。

## 输入与资源保护

沿用原匿名获取及安全边界。公开来源只接受规范 HTTPS B站 BV URL 及合法分 P；不加载用户配置、Cookie、netrc、插件或模型认证。公共 DNS、TLS 主机名、协议、媒体域名和重定向逐项校验；签名媒体地址和原始异常不写入公开日志。

代理 CONNECT 403 或网页 HTTP 412 的公开 API 恢复、安全媒体备份回退、BV/分 P/完整时长及实测媒体检查保持。下载、重试、探测默认共享1800秒期限。原生解码累计600秒、单次60秒；连续采样通过有超时清理的 FFmpeg 子进程流式处理，不缓存全视频原生帧。采样最多4097帧、单帧2000万像素、长图8000万像素；中值窗口最多13帧，并按像素量进一步限制。

取消或失败停止解码进程、清理临时资源，已有有效记录不替换为半成品。原视频与派生产物分开保留，路径、hash 和不覆盖规则继续执行。未知宿主成本为 null。

## 首版范围

已有白底多行、固定比例的纵向滚谱，优先适配停驻后向上推进。缩放、横移、复杂翻页及没有谱面的演奏视频不纳入首版。历史版本通过 Git history 获取，回滚使用独立 checkout 及新任务目录。

新主线的验证范围和限制见[验证记录](verification.md)，产品取舍见 [ADR 0004](adr/0004-longshot-approximate-score.md)。历史样本通过不自动构成本次真实生图或跨宿主验收。
