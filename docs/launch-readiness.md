# 当前交付范围

当前包仅提供 PDF。Agent 人工取帧和确认接续，使用一份具体来源审阅；宿主生图优先，失败时矢量兜底，最终实际查看全部页面后交付。运行与恢复读取[阶段指南](agents/stage-recovery-layout.md)，安装读取[安装指南](install.md)。

支持已有白底多行、固定比例、向上推进或可确认有序翻页的视频。矢量不能恢复完全隐藏的记号。来源未决继续阻止完整交付。

历史 Codex 整曲验收、旧 MIDI 回读和自动扫描实验保存在[验证记录](verification.md)及 Git 历史中。它们不代表本次清理版本的新真实来源、真实宿主生图或跨宿主验收。本轮离线验证的实际结果记录于 verification.md，未执行项明确标记。
