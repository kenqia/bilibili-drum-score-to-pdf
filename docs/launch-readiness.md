# 当前交付范围

当前产品提供 Python/CLI 自动视频转图像鼓谱 PDF，以及可选的匿名网站。支持固定比例白底纵向滚谱；自动识别到来源变化、缺段、动态内容或无法消歧的接续时拒绝发布。完成结果保留实际来源、PTS、hash、限制与 `reliable=false`，不代表音乐逐符号校对。

CLI 交付 PDF、全部预览、manifest 和原生采样。网站交付 PDF、全部预览与诚实来源记录；worker 清理原生采样、长图和下载暂存，manifest 明确不能仅凭保留目录重建。默认结果保留 24 小时，到期拒绝访问并物理清理已登记的受管文件。参数与容量范围见[网站运行指南](script-product/website.md)。

用户认可 #70/#71 的四份原谱面后，要求放大并减少尾页留白，已按要求交付放大均衡版。#72 已完成本地网站进程及安装验证。#73 继续收口生命周期、容量、安全清理、迁包、测试和旧产品退役，实际结果见[产品收口实验记录](experiments/2026-10-21-issue73-product.md)与[验证指南](verification.md)。仓库内旧 Skill 已退出，已安装的 Skill 和历史任务不自动修改或迁移。
