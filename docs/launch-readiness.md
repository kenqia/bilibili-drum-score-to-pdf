## 已确认

- 首批用户已经使用 Codex 等视觉 Agent，愿意安装 Skill。
- 输入为视频中已有的固定比例、白底多行鼓谱。向上滚动需有可靠重叠，有序翻页需能确认接续。横向滚动和没有谱面的演奏视频不在首发范围内。
- 用户报告 Agent 几乎每次都能自行完成，过程中没有修改代码。这是实际使用经验；尚未整理样本总数、干预情况和失败分母，不能换算成成功率。
- 用户希望跨主流 Agent 使用，并提供自然语言安装方式。这是产品目标；没有完成各宿主安装和整曲交付验证，不能把通用指令等同于已验证兼容。
- Agent 自主交付要求用户给出输入和输出位置后，无需纠错或催促，Agent 自行审阅、补采、恢复并交付正确 PDF。正常工具授权不计干预，用户重新发起或纠错后成功另列统计。中间 prepare 的 waiting 不直接计为最终失败，导出后还须核对完整性、符号和顺序。
- 本轮是首发前的最终产品测试，用于取得产品数据与效果。用户接受下述样本规模、质量标准和单视频预算；这些标准不构成对所有输入的产品承诺。

## 已确认的最终测试标准

- 10 个不同视频，覆盖至少 3 位作者，包含向上滚动和有序翻页，以及不同曲长、谱面密度和光标遮挡。
- 先确定样本，再执行转换；等待和失败都保留。重复运行同一视频不增加独立样本数。旧成功样本可纳入，但从新任务开始，不复用旧决定或旧任务恢复结果。
- 至少 9 个样本在预算内自主正确交付，且本批次没有错误 PDF 被报告为完整成功。等待或失败须有明确结果和原因。
- 每个视频累计执行预算 30 分钟，包含获取、Agent 审阅、补采及 PDF 检查。超预算记为未交付，后续恢复另记，不覆盖首次结果。额度等外部中断单独注明，不以新计时起点掩盖已有耗时。
- README 公布实际样本数、交付数和实测耗时，暂不承诺固定完成时间，也不把小样本通过比例等同于全部适用视频的成功率。

每个样本记录来源、作者、布局、视频时长与实测分辨率，绑定源码版本、宿主可见标识、模式和运行配置。转换记录最终状态、用户干预、累计耗时、行数、页数、来源核查和逐页视觉审核结果；同时保留决定、实际 PTS、原裁剪来源与结果文件。图像生成数量和实际呈交数量分开，无法测量的模型成本保留 null。
