# 当前交付范围

仓库统一提供两条独立路径，产品边界见 [ADR 0007](adr/0007-independent-skill-and-website.md)。

Skill 恢复远端 main 的自包含目录、安装工具与协议，默认以长截图、完整谱行排版和全部页面审阅交付。可选重绘、矢量及任务恢复遵守本包协议。恢复分发不代表新增真实来源、宿主或音乐校对验收。安装和验证分别见 [Skill 安装](skill-install.md)、[Skill 验证](skill-verification.md)。

程序与网站提供自动视频转图像鼓谱 PDF，支持固定比例白底纵向滚谱。已检测的来源变化、缺段、动态内容或无法消歧的接续会拒绝发布。完成结果保留实际来源、PTS、hash、限制与 reliable=false，不代表音乐逐符号校对。

CLI 交付 PDF、全部预览、manifest 和原生采样。网站交付 PDF、全部预览与来源记录；worker 清理原生采样、长图和下载暂存，默认结果保留 24 小时，到期拒绝新访问并清理登记文件。参数见[网站运行指南](script-product/website.md)。

网站已在 <https://drum.kenqia.top/> 开放。2026-10-22 使用 BBDownNext 2.3.0 有界构建保持服务器直连，完成真实小星星转换、取消/中断重试、预览下载、备份恢复及隔离短期限清理验证。此前 HTTP 412 待开放状态属于历史；最新证据及失败修正见[接入与公网验收](experiments/2026-10-22-bbdown-integration.md)。本轮仓库整理不改生产部署，不自动安装 Skill，也不迁移任何任务。

两套产品的本地测试、远端 CI、真实来源与实际看图分别记录；任一通过不替代另一项验收，也不保证所有 B站视频均可匿名获取。
