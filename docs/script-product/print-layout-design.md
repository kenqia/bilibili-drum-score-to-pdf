# 在线人数与 PDF 重新排版设计

本页记录 2026-10-24 用户确认并授权本地实现的产品设计。范围为程序与网站，不修改独立 Skill。

## 已确认的行为

网站显示近似在线人数。同一浏览器的多个标签页计为一个访客，不同设备分别计数；后台页面持续发送心跳时仍计入，超过六十秒无心跳后移除。页面显示“当前约 N 人在线”。浏览器使用 localStorage 中独立的随机访客 ID 协调标签页，不关联任务访问凭据。服务只在有界内存中保留六十秒内的心跳，重启后重新累计。存储被禁用时显示统计暂不可用，不能据此识别真实人数。

用户可以在转换完成后重新排版，不重新获取视频、解码或拼接谱面。首版保留原谱每行小节数，不提供改变每行小节数的有效控件。

排版采用每页行数优先。界面只提供纸张和带“自动”选项的“每页目标行数”调整条，不提供方向选择。程序自动计算五线谱高度、鼓谱行间距与总页数，不提供这些从属参数的独立控件。五线谱高度是第一根线到第五根线的打印距离，以毫米计。谱行内容等比缩放，五线谱内部线距随高度变化，不独立变形。鼓谱行间距指上下完整谱行之间的空白。

每页目标行数是排版偏好，不保证每一页恰好达到该数。程序在纸张宽高、可读性和完整记号的约束内自动调整；目标行数过多时降低至安全可容纳的行数，并提示实际调整，例如“已自动调整为每页 6 行”。末页可以不足。没有安全空隙的连续行组整体保留，不强行分割。

纸张提供 A4、A3、A5，统一使用纵向，默认 A4。切换纸张后重新计算布局与页数。

调整条同步显示数值，并支持直接输入。用户点击“应用设置”后统一生成 PDF 和全部预览；拖动调整条本身不触发整份生成。生成期间保留上一份可用结果，失败时显示原因，成功后统一切换到新结果并回到第一页。提供“恢复自动排版”按钮。

默认版本保留不变。调整结果临时且独立，仅供当前页面预览与下载，不建立可回访的历史版本，不改变任务链接的默认结果。保存或分享的任务链接永远打开默认版本；不同访问者的调整不覆盖默认版本或彼此的临时结果。刷新、关闭页面或重新打开链接后恢复默认版本。已经下载到本地的 PDF 保留。临时调整不延长原任务的有效期。

默认排版优先保证可读性，自动选择大小与每页行数，并减少各页下方不必要的空白。默认 PDF 本身的页底留白改善纳入本次验收，用户首次打开任务链接即能受益；临时调整用于个人打印偏好。末页允许合理留白，不为填满页面过度增大行距。

自动计算不能裁切完整谱行或关键记号。

已有任务不纳入本次兼容范围，不要求从其默认 PDF 恢复排版能力，也不迁移或重新转换已有任务。

每次重新排版都重新计算页数。总页数可以增加或减少，不能沿用原 PDF 页数。预览图片、预览页码、总页数和下载 PDF 必须属于同一份完整排版结果；不得混合不同设置的结果，页数减少后不得留下旧的多余预览页。

## 改动前的实现与限制

改动前，`src/drum_score/imaging.py` 的 `paginate` 将谱面连续条带作为图片嵌入 A4 PDF，使用十二点页边距、统一缩放和原行距；`_page_strips` 在最少可行页数下均衡条带高度。这些约束可以产生页底留白，单纯继续缩小页边距不能解决全部问题。

当前程序检测完整谱行或不可安全分割的连续行组，没有小节级音乐结构。调整每行小节数需要额外的识别与重排能力，首版不承诺该能力。

网站继续只保留 PDF、预览和清单，不改变持久保留策略。重新排版通过已安装的 Poppler 工具 pdfimages 提取 PDF 中嵌入的原像素图片，再组合为临时派生谱面。重新组合不声称恢复已删除的原生来源。没有新增 Python 依赖或数据库 schema。

## 实现与限制

每页目标行数支持 1 至 16。行数是偏好，谱面不会为了满足过多行数而缩得比纸张宽度对应的比例更小；超高的不可拆分行组按整组安全缩放。实际可容纳行数与调整提示随结果返回。

自动排版紧凑安排完整行组，只移除纯白的纵向空白，保持所有非白像素。页间统一比例，行组间留白自动计算，上限四十八点。短末页、背景非纯白或连续边框连接的行组仍可能有明显页底空白，不通过删除边框或裁切记号填满页面。

临时排版使用独立进程，单服务数据根同一时刻最多一个重排，不占用视频转换队列或提交额度。超额请求返回 503，不自动排队。子进程受九十秒外层期限、六十秒 CPU、三 GiB 虚拟地址空间及一百二十八 MiB 文件上限约束。

临时材料在原任务受管 attempt 中登记身份，先实际分配一百二十八 MiB 预留文件，纳入共同容量检查；实际材料另受单任务预算和一百二十八 MiB 上限约束。父进程轮询临时总量和磁盘余量，guardian 在父进程意外退出后终止剩余子树并清理确切临时根。整树含 guardian 被终止后，worker 启动恢复按登记身份清理，未知根不接管；活跃重排锁阻止恢复过程提前删除材料。Linux 下运行，不宣称这些采样和 rlimit 等价于独立 cgroup 的 RSS 硬限额。

单次结果上限三十二 MiB JSON，最多六十四页；包含 PDF 和全部 PNG 的 base64。服务在响应前清理临时目录，浏览器只持有临时 Blob，不产生可回访的排版链接。每次重新排版需要原任务能力凭据，生成期间与返回前重复检查原任务期限。

## 谱行边界细分

2026-10-29 经用户验收后，本地 main 的默认转换和临时排版共用 `staff_boundaries.py` 与 `staff_ownership.py`。此合入不表示已部署到线上。
五线检测和已有安全水平边界保持原实现。只有原来合并的相邻谱行才尝试细分。
视频获取、配准、合成、去重和专家兜底路由不变，不新增依赖或数据库字段。

检测图保留最小 RGB 通道小于 245 的墨迹。以下两个例外只影响边界检测，不擦除交付像素：

- 实际图片边缘的连续中性灰列。每列所有像素亮度至少 190、小于 245，变化不超过 12、色差不超过 4；宽度严格小于 `min(8, width//100)`，相邻内列至少 98% 像素达到 245。
- 独立八连通浅灰岛。面积最多 8 像素、外框最多 4×4，所有通道至少 240、色差不超过 4。

新增切口在上行第一根线下方五倍线距至下行第一根线上方一倍线距之间查找。
基线 `82f4d68` 遇到游离实质记号时保留整组。当前实现冻结已锚定黑色内容，以同 x 上下首命中 owner 和多列证据归属悬空记号，再计算凸凹路径。
S12 第 103 小节上方 `o+` 留在第 99 小节所在上行块，用户明确接受此例外后授权合入。S12、S14 最大行组分别从 13、35 行降为 7、10 行，仍未全部分开。其余 18 源的页面检查见[后续验证](https://github.com/kenqia/bilibili-drum-score-to-pdf/blob/4d75de5/docs/experiments/2026-10-29-staff-boundaries-remaining18.md)。同高度带可能合并不同语义对象，当前规则不能保证所有记号归属。具体阈值、分组限制和历史失败证据见[同列归属实验](https://github.com/kenqia/bilibili-drum-score-to-pdf/blob/4d75de5/docs/experiments/2026-10-29-vertical-staff-ownership.md)。
上下行存在共享组件时继续保护整组，不靠方向推断连接归属。
独立后置检查拒绝把原八连通组件分到两行。

交付将原 RGB 像素分配给唯一行图，曲线外仅填充白色。
该步骤不改变保留像素的颜色、水平位置和行内几何关系，页间仍使用统一比例。
灰边不属于音乐组件保护范围，随相应原图行保留。
检测条件仍是几何启发式，不能证明所有独立记号的音乐归属。已存在的水平边界不重新判断。
细小浅色真实记号也可能符合灰岛条件，因此结果始终 `reliable=false`，需要查看实际页面。

单个分析带最多 200 万像素，宽度最多 8192；每次最多探测 512 个新边界。
单条路径最多 512 段，总计最多 8192 段。超限保留原组。
曲线裁图的外框面积加提取时的八像素间隔若超过 2000 万像素，整次细分回退原行组，不放宽临时排版上限。
已有直线分组在接近上限时仍可能无法提取，维持受控 `layout_unavailable`，默认 PDF 可下载。

转换 manifest 的 `pagination` 记录算法版本、灰边列、原/新组数、各组行数和逐边界原因。
`path_runs` 使用 `[x_start, x_end, y]`，横坐标左闭右开，表示该区间的原图分界 y。
`page_regions` 使用各边界的中位数，仅作兼容页区间；曲线真实分配以 `path_runs` 为准。
详细证据不进入网站持久任务摘要或数据库 schema。
保留多行组时，转换警告 `joined_staff_rows` 和排版信息提示最大连续行数。
