## 执行边界

首轮调用固定使用 `--no-ocr`，其他提取、重采样、ensemble 和裁剪参数使用原包默认值。不安装或调用 Tesseract，不启用 OCR。原包自带的小节号图块比较仍可能参与画面匹配，关闭 OCR 不表示关闭所有小节数字区域比较。

只有归一化后与默认值完全相同的选项允许专家兜底。显式选段、手动谱区或关闭覆盖物忽略的任务继续使用首选算法，失败后维持原错误。界面在高级选项处说明限制。

Python `convert` 和 CLI 保持原有首选算法行为。网站在现有受监督转换进程内，将本次已下载的视频交给专家入口；不重新下载、不新建队列任务、不刷新输入、时间、内存或磁盘预算。只有 `unsupported_layout` 和 `discontinuity` 允许兜底；笼统的转换错误和解码错误不在范围内。首选成功的 PDF 不经过专家程序。

适配层生成全部页面预览和 manifest，继续使用现有发布、所有权登记和到期清理。原包 HTML、内部报告和日志只存在于本次私有暂存目录，不作为未登记文件遗留在结果根。公开 manifest 的 `expert` 保存原包身份、首选失败码、审计状态、裁界疑点及请求取帧秒数；不发布私有路径和原始异常。`conversion.engine=expert_v6`、`conversion.needs_review=true` 和明确警告用于标识兜底结果。

任务 API 和数据库摘要继续使用既有字段，不增加顶层 `expert`。详细证据保存在 manifest 和私有整理记录中。旧发行的维护工具因此仍可核验这些结果，避免回退算法后无法备份或恢复。

48 源效果验收在合入后进行，包括 S01–S20、F01–F20 和此前八源。此前明确跳过的 r9 不属于八源，不因历史九源评估而新增。本轮合入前先运行针对性合成验证、程序回归、离线重放和准确发行检查，不把这些检查冒称 48 源效果通过或音乐校对。
