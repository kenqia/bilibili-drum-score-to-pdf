## 作者评论和公开来源

实际读取三条视频 `x/v2/reply?type=1&oid=<aid>&pn=1&sort=2` 的第一页热门顶层评论和置顶回复，均返回 code 0；没有读取登录信息或发送评论。此检查不声称覆盖所有评论或回复。

KiLLKiSS 作者本人置顶 [b23 商城链接](https://b23.tv/mall-2A7Uq-l4An)，匿名跟随重定向后是 B站商城商品 11217461。标准样本作者本人置顶 [b23 商城链接](https://b23.tv/mall-2A7Uq-l4HF)，是商品 11217861。两份商品页 HTML 均 HTTP 200、2863 字节，只包含动态页面启动代码；没有可读取的鼓件图例，也没有获取或购买商品文件。

标准样本一条观众评论说“间奏加了开镲舒服多了”。这不能定位某个符头，也不是作者图例，不能据此认定所有高位 crossed oval 是开放踩镲或某种吊镲。KiLLKiSS 评论讨论速度和底鼓，没有鼓件表。第三条公开第一页只有鼓励性评论，没有图例。

Exa 搜索找到 [看哦爱随风的打鼓谱空间](https://www.dagupu.com/space/3)，搜索摘要列出多份署名同作者的谱，包括 ONE OK ROCK 和 MY FIRST STORY 的曲目。它可以证明搜索索引存在该署名空间，不能证明本文三曲的鼓件映射。

直接 HTTPS 获取作者空间失败于证书校验（curl exit 60）；没有关闭 TLS 校验。按 agent-reach 网页后端调用 Jina 时，匿名请求返回网络信誉阻止（HTTP 401），没有按其要求配置认证。没有取得空间原图，不能宣称看过其图例。Exa 定向查询没有返回该空间的图例或本次两曲源谱。

其他找到的《小星星》网页分别属于作曲大师、群音殿、五线谱网、好乐谱等，编配身份或版本不同。没有确认与当前亮-星视频和谱面署名存在联系，未将这些谱的映射移用到第三样本。
