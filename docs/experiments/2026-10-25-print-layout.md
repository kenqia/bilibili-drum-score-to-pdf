# 在线人数与临时打印排版验证

2026-10-25，本轮在 `codex/parallel-conversions` 分支、基线 `b6b8220deefc5e93d4495089103173efa4acf927` 上完成本地实现。用户确认的行为见[排版设计](../script-product/print-layout-design.md)。未推送或部署，独立 Skill 未修改。

## 实现范围

网站显示六十秒心跳窗口内的近似在线访客，同一浏览器的多个标签页使用独立访客 ID 去重。结果页支持纵向 A4/A3/A5 和自动或 1 至 16 行的每页目标行数，自动计算缩放与行间距，保留原谱每行小节数。

点击应用后，从默认 PDF 提取已有图片，在受限独立进程生成临时 PDF 与全部预览，不重新获取或解码视频。页数、预览与下载统一切换，失败保留上一份完整结果。临时版本不进入任务历史、不延长期限；重新打开保存的链接仍为默认版本。默认排版本身也改为完整行组紧凑排列，仅移除纯白纵向空白。

## 失败与审阅修复

初次全回归中，旧维护测试的稀疏谱面在紧凑排版后可容纳于一页，使其多页前提失效。将合成谱面从九行扩展到十七行，保留原多页断言，再完成上述全量回归。转换测试将旧的每页单幅嵌入图假设迁移为全部行组按绘制顺序还原与像素完整性断言，没有删除仍适用的完整性要求。

双轴静态审阅以同一基线分别检查 Standards 与 Spec。发现并修复了临时目录先于写入进程停止被删除、临时材料缺少受管恢复身份、预留空间未纳入共享容量，以及恢复默认时 PDF 与预览短暂不一致。复审均报告没有新增可操作发现；静态复审没有替代测试执行。

首次安装冒烟脚本的仓库外标记不足以证明执行目录，随后用实际 `/tmp` 工作目录与 `-I` 绝对解释器重新运行两份环境，最终报告采用后一次结果。

## 剩余限制与回滚

连续边框、非纯白背景、不可安全分割的行组和短末页仍可能留白，不通过裁切记号填满页面。在线人数受浏览器存储、后台心跳节流和六十秒窗口影响，是近似统计。

Linux 进程生命周期已在本机验证，未在生产 cgroup 预算下压测或部署；rlimit 与采样检查不能当作 RSS 硬限额。未重跑独立 Skill，没有新增音乐准确性承诺。

本轮不改变数据库 schema，不迁移已有任务。部署与远端写入需要另行授权。若后续切换版本，应先保留匹配的原发行和数据副本，按既有维护流程停服切回，不覆盖原输出或刷新原期限。
