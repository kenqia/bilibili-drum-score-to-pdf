# README 流程演示

用户于 2026-10-15 确认深色、真实成果、静音循环 GIF 的方向。

## 目的与交付

面向准备使用项目的鼓手和视觉 Agent 用户，展示已有谱面视频如何整理为 A4 PDF。源工程为 1280×720、12 秒、15 fps，主交付压缩为 960×540、12 fps 的无限循环 GIF，附静态流程图与 README 头图。画面为流程编排，不表示实际执行耗时。

## 素材

使用 #58 标准曲《可惜没如果（新版）》已保存的来源首帧、39/43/47 行和两张最终页面。原视频 BV1rH4y1R7Rk，上传者「看哦爱随风原创鼓谱」，谱面署名「陈老师」。来源详见 ../../experiments/issue-58-standard-pdf.md。素材只用于展示，不对音乐符号做修复，不新增转写或验收结论。

## 构图与节奏

单场景，三个固定区域始终呈现完整工作关系。0–3 秒强调原截图，3–6 秒完整谱行依次落位，6–9 秒 A4 页依次进入，9–11 秒保持全貌，最后 1 秒返回开场构图。连接标记随步骤推进。无旁白、音乐或模拟终端日志。

## 视觉规范

深墨背景 #151716，暖白文字 #F2EFE7，琥珀色 #D5A45B，次级文字 #B9BDB4，结构线 #454940，纸张保留原始图片颜色。中文用本机 WenQuanYi Zen Hei，英文与数据用 DejaVu Sans Mono。三个区域以实际素材为视觉中心，避免装饰仪表盘。标题、正文及来源脚注保持可读。

## 验证

用 HyperFrames lint、validate、inspect 与 check 检查；查看起始、过程及最终静帧。回读 GIF 的尺寸、帧数、循环与时长，控制体积。静态替代图供不播放动画时查看。未知音乐准确率与运行成本不加入画面。
