# 有界解码验证

本轮以统一 CLI 验证临时帧占用。固定谱面被编码为 32 秒真实视频，转换期间监测独立 TMPDIR。旧实现累计 68 张 PNG，超过测试设定的 32 张上限，红测成立。迭代批次实现通过同一测试，不在分析开始前生成全片 PNG。

每批输入最多 10.5 秒，正常帧采样间隔 0.5 秒。消费后删除已无用途的临时帧，仅保留上一可读参考；疑点原图已有任务 evidence 副本，接续、边界、候选与光标互补证据按原规则保留。因此上限只针对常规临时采样缓存，交付证据仍随内容和疑点增长。

逐批检查 source PTS，跨批重复帧不会重复进入还原。额外解码最后一秒确认真实末帧。32 秒固定帧测试末帧为 31.75 秒，12 秒变帧率测试末帧为 11.75 秒，均保留 3 条谱行并生成 PDF。最终三项 CLI 测试通过，共 35.637 秒，包含固定帧率、变帧率与 SIGINT 中断清理；中断后没有残留解码目录或 PDF。

每批 ffmpeg 最多 120 秒，所有常规批次累计解码进程时间最多 600 秒，末帧核查另限 60 秒；这些预算不包含图像分析与 PDF 排版。解码使用两个线程，PNG 编码使用一个线程，以限制单批进程资源峰值，不更改输出像素。

并发验证期间，主机 swap 已满。一次 cross regression 的 ffprobe 耗时超过 30 秒，结果为 unreadable_input；同一光标测试单独复跑通过。这是本次实际验证中的资源干扰，不能删掉失败记录。后续完整回归采用串行运行。

五分钟 1920×1080、2 fps 固定谱面基准中，基线 67a34da 与本次迭代实现均输出 3 行、1 页，末帧 299.5 秒。逐行打印像素、顺序、边界、seams 与 issues 相同。临时 PNG 峰值从 602 张、35.21 MiB 降到 23 张、1.36 MiB；进程树 RSS 峰值从 440.13 MiB 降到 304.83 MiB。修复后每分钟 RSS 中位数从 204.49 MiB 增至 209.26 MiB，保留观察元数据仍有小幅增长。

扣除人工暂停的耗时约 299.83 秒和 302.70 秒，本轮不声称提速。基线曾与其他验证并发，WSL 文件扫描的实际采样间隔中位数为 1.734 秒，修复后为 0.148 秒；短暂峰值可能漏采，RSS 汇总会重复计算共享页。这些数字是本环境观察，不是严格资源上限。此记录描述合成视频，不代表真实整曲打印验收。
